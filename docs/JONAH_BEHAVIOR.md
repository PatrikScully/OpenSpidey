# Jonah encounter behavior

`JonahBrain` ports the original PC decision routines at `0x446470` (AI), `0x446340` (initialization), `0x444CF0` (pleading), and `0x445B80` (panic). The idle branch lives inside AI. The original executable remains the reference because these routines are absent from the recovered C++ actor implementation.

`JonahBrainState` composes the existing constructor state, body motion, AI procedure list, and shared CMessage queue. Constructor and procedure behavior flags refer to the same source field at `0x2A8`. Jonah signals at `0x218` remain independent of procedure completion flags at `0x288`. Source input signals at `0x44` bind directly to the script/registry pending word and remain independent of physical collision at `0xE0`. The constructor/script wait field `0x230` is separate from the AI wait field `0x1F8`, which directly aliases the body's limited-motion timer.

Each AI visit recovers the Scorpion handle, decreases speech and panic sound timers, updates the hiding signal, removes the previous horizontal displacement, calls the actual `CBaddy::DoPhysics(0)` body/recorded-motion transport, and builds the transform. It then filters messages, executes and retires AI procedures, plays animation-frame sounds, dispatches the current state, resolves contact with the Scorpion identity cached at entry, and draws the shadow. Procedure callbacks can change the state before dispatch. The separate `SetMovementHeight` transport invokes source `CBaddy::SetHeight` against the real terrain/support owner.

Pleading waits for the actual Scorpion module's current target. Its transition clips and timer depend on the current animation, setup mode, speech suppression, Scorpion victory, and source clock. The alternate speech selection shares its storage with the speech timestamp in the PC executable; the port preserves that alias. Initialization and pleading decrement the AI wait timer, while panic increases it once per AI visit. Pleading restores setup `(0x02020202, 0x00000102)`; panic restores `(0x0A0A0A0A, 0x0000000A)`.

Panic sends message9 containing the actor and current waypoint positions to Scorpion. It probes an authored path with clearance55, waits eleven visits before the next waypoint check, and uses the existing Q12 heading and distance rules. The source can transition back to movement only after both path points are accepted.

`IJonahBrainHost` requires the actual actor/module/animation/audio/world transports. It also exposes the remaining `FollowWaypoints`, `Hide`, `TakeHit`, `Die`, `GoAroundScorpion`, and shadow leaves. There is no production Godot Jonah actor connected to this brain yet, and this slice does not establish complete boss AI or playable L2A2 progression. A host must supply these dependencies before production use; the Core port supplies no fallback actor or automatic no-op behavior.

`tools/reference_jonah_brain_vectors.py` runs whole original routines in an isolated Linux/i386 PE observer. Only Windows exception-registration and explicitly listed host transports are replaced. Original timer arithmetic, neutralization, state flags, speech selection, message guards, animation decisions, and dispatch remain executable. The 1,480-case fixture records51 fields at every callback and covers all27 host callback kinds, including failed allocation, stale pointer/validation handles, clock wraparound, animation boundaries, procedure-driven state changes, and message cleanup. `JonahBrainTests` compares these observations against the Core port. Opaque movement, hit, hide, death, collision, animation, and rendering callbacks validate transport ordering rather than their unported implementations.
